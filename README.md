# FreshMart – Grocery Mart Management System

A Python Flask mini project with an attractive web dashboard.

## Features
- Dashboard: product count, stock units, inventory value and low-stock count
- Add, search, edit and delete products
- Low-stock alerts
- Billing: validates available stock and reduces inventory automatically
- Sales report and print option
- SQLite database is created automatically with sample products

## Run on Windows
1. Extract this ZIP.
2. Open the `FreshMart` folder in VS Code.
3. Open Terminal in that folder.
4. Run `python -m venv venv`
5. Activate it: `venv\\Scripts\\activate`
6. Install: `pip install -r requirements.txt`
7. Run: `python app.py`
8. Open `http://127.0.0.1:5000` in your browser.

Keep the terminal open while using the website. Press Ctrl+C to stop the server.
This is a college demo project; do not deploy publicly with debug mode enabled.
